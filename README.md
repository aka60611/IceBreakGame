# 何人正解？

3〜6人で遊べる、アイスブレイク向けのPython製Webゲームです。出題者は「何人が正解するか」という秘密のお題に合わせて質問を考え、ほかの参加者はその目標を知らずに回答します。

## 起動方法

Python 3をインストールしたうえで、ターミナルからプロジェクトのフォルダーへ移動して実行します。

```bash
cd ~/IceBreakGame
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python3 app.py
```

ブラウザで http://127.0.0.1:5000 を開きます。初版は1台の端末を参加者間で順番に回して遊ぶ想定です。

## 遊び方

1. 参加人数を3〜6人から選び、名前を登録します。初期人数は3人です。
2. ランダムに選ばれた出題者の名前を確認します。出題者だけが画面を見て「お題を確認する」を押します。
3. 出題者は表示された目標人数を見て、その人数が正解しそうな質問と正解を入力します。
4. 出題者以外が順番に回答します。入力中は現在の回答者の欄だけが表示され、ほかの人の回答は見えません。
5. 全員の回答後、出題者が正解者を選び、正解人数と目標人数を公開します。
6. 「次のラウンド」で続けます。前回の出題者は次の出題者候補から外れます。
7. いつでも「人数登録に戻る」を押すと、試遊データを初期化して参加人数の登録に戻れます。

## 得点

- 正解した回答者：1点
- 出題者が目標人数ぴったりにできた場合：3点
- 出題者が目標人数と1人差だった場合：参加人数が3人なら0点、4〜5人なら1点、6人なら2点
- 目標人数との差が2人以上の場合：出題者は0点

## 実装メモ

- ゲーム状態はFlaskのブラウザーセッションに保存されます。
- 正解者の判定は出題者が回答を確認して手動で行います。
- `.venv/` などローカルのPython環境はGit管理対象外です。
