# 何人正解？

3〜6人向けのアイスブレイクゲームを遊ぶための、小さなPython製Webアプリです。

## 起動方法

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

表示されたローカルアドレス（通常は http://127.0.0.1:5000 ）をブラウザで開きます。1台の端末を順番に回して遊ぶ想定です。

## 遊び方

1. 3〜6人の名前を登録します。
2. ランダムに選ばれた出題者だけが画面を見て、目標人数を確認します。
3. 出題者は、その人数が正解しそうな質問と正解を登録します。
4. 出題者以外が回答を入力します。
5. 出題者が正解者をチェックして結果を公開します。

## 得点

- 正解した回答者：1点
- 出題者：正解者数が目標ぴったりなら2点、目標との差が1人なら1点、それ以外は0点

この初版は、出題者が回答を確認して正解者を選ぶ方式です。ゲーム状態はブラウザのセッションに保存されます。
